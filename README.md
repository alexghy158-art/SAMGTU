# Трекер · СамГТУ

Личный трекер: пары, смены, деньги, магистратура, кино. Статический сайт без сборки и без бэкенда, хостинг — Netlify.

## Разделы

- **Сегодня**: пары на сегодня (с отметкой «идёт сейчас»), ближайшая смена, лимит трат на день, горящие дедлайны, заметка дня.
- **Учёба**: расписание по неделям, посещаемость по предметам, задания, материалы.
- **Работа**: смены, расчёт оплаты, цель на месяц, пары, которые пересекаются со сменами.
- **Деньги**: кошельки, дневной лимит до аванса или зарплаты, операции, расходы по категориям.
- **Магистратура**: мои вузы и их статусы, каталог программ, дедлайны, документы, язык, черновик SOP, гайды.
- **Кино**: список «хочу посмотреть», статусы, оценки, случайный выбор.
- **Данные**: скачать или загрузить бэкап (подходят и бэкапы старой версии), сброс.

## Где лежат данные

Всё хранится в `localStorage` браузера, на сервер ничего не уходит. Чтобы перенести данные на другое устройство, используйте **Данные → Скачать бэкап / Загрузить бэкап**.

## Структура

```
index.html            оболочка страницы
css/styles.css        стили (светлая и тёмная тема)
js/app.js             роутинг (#today, #study, …) и сохранение
js/store.js           состояние, миграция со старой версии, бэкап
js/logic.js           оплата смен, пересечения с парами, дневной бюджет
js/pages/*.js         по файлу на раздел
data/schedule.js      расписание пар (сюда добавлять новый семестр)
data/catalog.js       каталог вузов и гайды
data/seed.js          стартовые смены, фильмы, вузы
netlify.toml          настройки Netlify
```

## Как обновить расписание

Добавьте пары в `data/schedule.js` в том же формате:

```js
{"date": "2027-02-09", "start": "08:00", "end": "09:35", "subject": "…", "type": "Лекция", "teacher": "…"}
```

Отметки посещаемости привязаны к сочетанию дата + время + предмет, поэтому при обновлении расписания они сохраняются.

## Ставки за смену

В `js/logic.js` → `PAY`: база 2000 ₽, 3 ₽ за гостя, 15 % с кальянов, 70 % с VR, 30 % с симрейсинга, 250 ₽ за отзыв.

## Запуск локально

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Через `file://` сайт не заработает: браузеры не грузят ES-модули с диска.

## Деплой на Netlify

1. https://app.netlify.com → **Add new site → Import an existing project → GitHub** → выберите репозиторий `SAMGTU`.
2. Branch: `main`. Build command оставьте пустой, publish directory — `.` (Netlify возьмёт это из `netlify.toml`).
3. **Deploy**. Дальше каждый пуш в `main` выкладывается автоматически.
4. Адрес можно поменять в **Site configuration → Change site name** (например, `samgtu-tracker.netlify.app`).
