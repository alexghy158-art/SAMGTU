# Трекер · СамГТУ

Личный трекер в виде приложения: учёба, смены, деньги, дела, привычки, дневник, контент-план «Твой ход», статистика. Работает в браузере и устанавливается на телефон как приложение. Хостинг — Netlify, облако — Supabase.

## Разделы

**Нижние вкладки (на компьютере — боковое меню):**

- **Главная**: живая карточка дня (какая пара идёт и сколько до конца, следующая пара через N минут), сервисы СамГТУ, пары, дела на сегодня, настроение и привычки, смена, «Скоро» (задания, экзамены, посты, дедлайны).
- **Учёба**: неделя, посещаемость по предметам, задания, **сессия** (зачёты и экзамены, оценки, средний балл, прогноз стипендии), материалы.
- **Работа**: смены с расчётом оплаты и **деньги** (кошельки, лимит на день до аванса или зарплаты, операции).
- **Жизнь**: **дела** со списками и напоминаниями, **привычки** (серии, тепловая карта за 12 недель) и **цели**, **дневник** с настроением и календарём.
- **Ещё**: статистика, «Твой ход», магистратура, кино, настройки.

Кнопка **«+»** быстро добавляет дело, расход, доход, смену, пост или экзамен.

## Синхронизация

Данные лежат в браузере (`localStorage`) и, если включить, в облаке Supabase. Работает по **коду синхронизации**: на первом устройстве «Настройки → Включить», на другом открыть ссылку `…#join=КОД`. В базе хранится только хеш кода.

Если правки сделаны на двух устройствах одновременно, трекер спросит, какую версию оставить.

## Push-напоминания

Плановая функция Netlify (`netlify/functions/send-reminders.mjs`) раз в 5 минут забирает из Supabase наступившие напоминания и отправляет push. Напоминания бывают такие:

- дела с датой и временем;
- пары, за 5–30 минут (включается в настройках);
- смены, за 30 минут — 3 часа;
- зачёты и экзамены, накануне в 19:00;
- посты «Твой ход», в день публикации.

Пара VAPID-ключей создаётся автоматически и хранится в Netlify Blobs. Публичный ключ браузер получает по адресу `/api/push-key`.

**На iPhone** push работает только для сайта, добавленного на экран «Домой» (iOS 16.4+).

## Устройство

```
site/                    сайт (Netlify публикует эту папку)
  index.html, sw.js      оболочка и service worker (офлайн + push)
  css/styles.css         дизайн-система, светлая и тёмная тема
  js/app.js              роутинг, навигация, кнопка «+»
  js/store.js            состояние, миграции, бэкап
  js/sync.js             облачная синхронизация, подписка на push
  js/reminders.js        какие напоминания отправить в ближайшие 14 дней
  js/logic.js            оплата смен, пересечения с парами, бюджет
  js/charts.js           графики (столбцы, полосы)
  js/pages/*.js          по файлу на раздел
  data/schedule.js       расписание пар (сюда добавлять новый семестр)
  data/catalog.js        каталог вузов и гайды
  data/seed.js           стартовые смены, фильмы, вузы, посты, привычки
netlify/functions/       send-reminders (по расписанию), push-key (/api/push-key)
netlify/lib/vapid.mjs    VAPID-ключи в Netlify Blobs
supabase/tracker.sql     схема облака (таблицы в tracker_private + RPC)
```

### Переменные окружения Netlify

| Переменная | Что это |
|---|---|
| `SUPABASE_URL` | адрес проекта Supabase |
| `SUPABASE_ANON_KEY` | публичный anon-ключ |
| `TRACKER_CRON_SECRET` | секрет, совпадающий с `tracker_private.secrets` (`name = 'cron'`) |

## Как обновить расписание

Добавьте пары в `site/data/schedule.js` в том же формате. Отметки посещаемости привязаны к сочетанию дата + время + предмет, поэтому при обновлении расписания они сохраняются.

```js
{"date": "2027-02-09", "start": "08:00", "end": "09:35", "subject": "…", "type": "Лекция", "teacher": "…"}
```

## Ставки за смену

В `site/js/logic.js` → `PAY`: база 2000 ₽, 3 ₽ за гостя, 15 % с кальянов, 70 % с VR, 30 % с симрейсинга, 250 ₽ за отзыв.

## Запуск локально

```bash
cd site && python3 -m http.server 8000
```

Сайт откроется на http://localhost:8000. Push локально не работает: для него нужны функции Netlify.
